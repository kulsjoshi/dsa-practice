# DSA Practice

Plain Kotlin project (no Android, no emulator). One file per problem, each with its own `main()`.

Run a problem: open its file, click the green ▶ next to `fun main()`, choose "Run ...Kt".

Day 1: hash maps, two pointers, stack
- day1/twosum              "For each number, ask the map if its partner is already there. If not, write myself down."
- day1/validanagram        "Same letters, same counts."
- day1/groupanagrams       "Anagrams share a fingerprint, and the fingerprint is the map key."
- day1/validpalindrome     "Two fingers, outside in. Skip the junk, compare lowercase."
- day1/containerwithmostwater  "Water is limited by the shorter wall, so move the shorter wall."
- day1/validparentheses    "Open goes on the stack. Close must match the top. Stack must end empty."
